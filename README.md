# BELJOUR web app (built static bundle)

Public build of the BELJOUR studio. Everything runs in your browser, including the Skin Moment
skin reading; photos never leave your device and no outside service is called.

Copyright (c) John Khan. All rights reserved. This repository contains only compiled
static output; third-party components keep their own licences (see THIRD_PARTY_NOTICES.txt).
